# TVMaze adapter fixture

The image and metadata are a real public Arcane backdrop returned by TVMaze.
Source: https://www.tvmaze.com/shows/55138/arcane-league-of-legends
Data: TVMaze, CC BY-SA (https://www.tvmaze.com/api#licensing).
Image rights remain with its owners. Browser network tests serve these bytes
for the corresponding exact image URL, and mock other show galleries empty.
This fixture is outside native assets and is not included in the APK.
